Agentes de Copilot: cuándo tiene sentido crear uno

Qué es un agente, qué herramientas existen para crearlo y cómo elegir la primera tarea.

Un agente es una versión de Copilot preparada para una tarea concreta: tiene instrucciones fijas, unas fuentes de conocimiento y, a veces, la capacidad de ejecutar acciones. Es la diferencia entre repetir el mismo prompt cada semana y tener un asistente que ya lo conoce.

Dos puertas de entrada

Microsoft ofrece dentro de Microsoft 365 Copilot un constructor de agentes de experiencia ligera, pensado para usuarios sin perfil técnico. Cuando hace falta más control, hay un camino para llevar ese agente a Copilot Studio con un solo paso, según el anuncio de Microsoft sobre las novedades de Ignite. Copilot Studio es la plataforma para crear, probar y publicar agentes, y permite publicarlos en Microsoft 365 Copilot y en Teams para uso personal, de un grupo piloto o de toda la organización.

Cómo elegir la primera tarea

Los candidatos buenos cumplen tres condiciones:

  1. Se repite cada semana o más a menudo.
  2. Tiene criterios que puedes escribir con claridad.
  3. Un error es corregible, no costoso.

Por ejemplo, un agente que responda preguntas frecuentes de un equipo usando un documento de políticas, o uno que prepare un resumen semanal con una estructura fija.

Qué escribir en las instrucciones

Trata las instrucciones como el manual de un empleado nuevo: qué hace, qué fuentes consulta, qué formato usa, qué no debe hacer y cuándo debe decir «no lo sé». La última parte es la más importante y la que casi todos olvidan.

Probar antes de compartir

Prepara diez preguntas reales, incluidas dos que el agente no debería poder contestar. Si inventa respuestas a esas dos, ajusta las instrucciones antes de dárselo a nadie.

Gobierno y costes

Quién puede crear agentes, qué datos pueden leer y cómo se facturan algunas funciones avanzadas lo decide tu organización. Habla con quien administre Microsoft 365 antes de publicar nada para un grupo grande.
